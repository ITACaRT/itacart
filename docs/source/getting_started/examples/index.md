# Example Notebooks

Five worked sessions that take the library from a first coordinate to a stored
cadastral record. Each is self-contained, each runs against the installed
package, and **each is executed when this documentation is built** — so the
outputs you read are the outputs the code produced, not outputs someone typed.

That also means an example that stops working stops the build. These pages
cannot drift away from the library.

They are written to be read in order, but any of them stands alone.

```{toctree}
:maxdepth: 1

inspect_a_cell
fill_a_parcel
traverse_the_grid

```

The conceptual material behind each step lives in
[Concepts & Guides](../../concepts/index.md); these pages link into it rather
than repeat it.
