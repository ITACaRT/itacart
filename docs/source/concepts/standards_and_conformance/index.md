# Standards & Conformance

Where ITACaRT sits with respect to the discrete global grid standards, and how
far.

The short version: **Core in full, EAERS partially**, and the divergences are
design decisions rather than gaps. The long version is the point of this
section — a claim of conformance is only worth what its qualifications say, and
these pages state each one with its scope and its measurement.

The table is not prose here. It is computed at run time by
`itacart.conformance()` and verified by the conformance test suite in
continuous integration, so what this documentation reports and what the package
asserts cannot drift apart.
