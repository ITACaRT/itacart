# Cadastral Workflows

Using the grid for cadastral work, from choosing a resolution to a finished
parcel.

This is where the rest of the documentation is put to work. Everything before
it describes what the grid is; these pages describe what to do with it when the
thing being represented is somebody's property and the numbers have legal and
fiscal weight.

The order is the order of a real job: decide whether a discrete global grid is
the right representation at all, pick a resolution from the scale of the source
mapping, choose how to represent the parcel, bound the error of the area you
report, put the geometry into a form two records can agree on, and then run the
whole thing end to end.
